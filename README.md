# Mesa do Mais e do Menos

Página interativa para crianças do 1º ano treinarem adição e subtração: juntar, tirar, comparar ("quantos a mais / quantos a menos"), quanto falta e troco.
Torres de blocos que se ligam um a um, ganhar e gastar, troco com as notas do real e uma revisão de 14 perguntas com explicação de cada erro.

Abra `index.html` no navegador. Funciona sem instalar nada.
